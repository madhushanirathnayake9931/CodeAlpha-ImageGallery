# 📷 CodeAlpha-Image Gallery

A responsive and interactive Image Gallery website built with HTML, CSS, and JavaScript. This project allows users to browse image categories, filter photos, and search through collection items easily.

---

## ✨ Features
- 🖼️ **Category Filtering:** Filter images by categories like Heritage, Ancient Ruins, Elephants, Food, etc.
- 🔍 **Search Functionality:** Easily search for specific images or topics.
- 📱 **Fully Responsive:** Smooth view across desktops, tablets, and mobile devices.
- 🎨 **Clean UI:** Simple, modern, and user-friendly user interface.

---

## 🛠️ Tech Stack
- **HTML5** - Structure and layout
- **CSS3** - Styling and responsive design
- **JavaScript (ES6)** - Interactive filtering and dynamic logic
